# MADALASHA ENTERPRISES ANALYSIS :
Detailed and Mesmerisisng Report Prepared of Madalasha Enterprises which shows the sale of firm in different fields..
# Process
* I created data of **MADALASHA** **ENTERPRISES** using excell in a sheet.
* Created pivot tables of nessessory things
* Used some formulas , functions and tools
* Created pivot chart of table
* Merge all the Charts with 2 **SLICER**.
# Datasheet Used
https://github.com/Hardic612001/Madalasha-Enterprises/blob/main/Madalash%20Enterprises%20data.xlsx
# Project Objective
The Madalasha Enterprises wants to create a report . So that they can understand and find 
out the total sale and field of sale area.
# Questions
* What amount of sale are done as per product,region and months
* Name the Salesman who sold most no. of prodects.
* List top 3 Sellers and Bottom 3  sellers.
* Total amount of products which are sold.
* Top 3 performing and sold products.
* Total no. of sale performed in count.
